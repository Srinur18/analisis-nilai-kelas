# Analisis Nilai Kelas

## Nama Proyek
Analisis Nilai Kelas

## Deskripsi Masalah yang Diselesaikan
Program ini dibuat untuk membantu guru dalam mengolah nilai mahasiswa.
Perhitungan nilai secara manual membutuhkan waktu dan berisiko terjadi
kesalahan, terutama ketika jumlah mahasiswa cukup banyak.

Program ini dapat membaca data nilai, menghitung statistik nilai,
menentukan kelulusan, dan menyimpan hasil rekap ke dalam file.

## Pengguna Sasaran
Guru, dosen, dan mahasiswa yang membutuhkan pengolahan data nilai
secara sederhana melalui terminal.

## Fitur

1. Membaca data nama dan nilai mahasiswa dari file.
2. Memvalidasi data nilai agar berada pada rentang 0 sampai 100.
3. Menghitung rata-rata, nilai tertinggi, dan nilai terendah.
4. Menentukan status kelulusan berdasarkan nilai minimum 60.
5. Menampilkan hasil analisis melalui terminal.
6. Menyimpan hasil rekap ke file output.

## Persyaratan
Python 3.x

## Cara Menjalankan

Pastikan terminal berada pada folder utama proyek.

Jalankan perintah:

```bash
python3 main.py
